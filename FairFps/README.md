# FairFps v0.1 (Abiotic Factor, UE4SS Lua)
FPS readout + scrolling frame-time graph via the engine's `stat fps` / `stat unitgraph`, on at start, F8 toggles. Frame-time log (avg/min/max every 10 s) in `C:/re/abioticfactor/fairfps_log.txt`.
Status: UNVERIFIED in game (shipping builds may strip stat commands; check log line `toggle true ok=true` and the on-screen graph).
